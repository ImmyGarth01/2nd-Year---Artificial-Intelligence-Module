## Searching ##
One type of goal-based agent is called a problem-solving agent, it formulates a goal and a problerm, searching ofr a sequence of actions that would solve the problem and then execute the actions one at a time 

##### Goals - these help organize behaviour by limitng the objectives that the agent is trying to achieve and therefore the actions it needs to consider 
##### Intitial State - where the agents starts in 
##### Action - A description of the possible actions available to the agent given a particular state 


A goal is considered to be a bet of world states, the agent's task is to find out how to act now and in the future so that it reaches a goal state. The searching part is the process of deciding what actions and states to consider given a goal 

##### Transition Model - A description of what each action does. specified by the function RESULT 

##### Successor - Referring to any state reachable form a given state by a single action 

##### Goal Test - Termines whether a given state is a goal state 

##### Path Cost Function - Assigns a numeric cost to each path
