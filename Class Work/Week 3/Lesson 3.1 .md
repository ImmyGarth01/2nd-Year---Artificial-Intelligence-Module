## Task Environment ##
Task Environments are essentially the "problems" to which rational agents are the "solutions
Task Environments include all in the acronym P.E.A.S which stands for: Performance, Environment, Actuators and Sensors

#### Properties of the Task Environment ####
- Fully observable vs partially observable - it os fully only if the sensors give us a full view of the environment, partially has missing data 
- Single agent vs multi-agent - A multi-agent system (MAS) has multiple agents that interact in the same environment.
- Deterministic vs Stochastic - if the next stage is completely determined by the current state and the action actuated by the agent then it is deterministc 
- Static vs Dynamic - an environment is dynamic if it could change whilst the agent is working 
- Discrete vs Continuous - think states, a taxi is a continous state
- Known vs Unknown - the environment itself
